# Wero1414 Lsusb

## How do I install these formulae?

`brew install wero1414/lsusb/<formula>`

Or `brew tap wero1414/lsusb` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "wero1414/lsusb"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
